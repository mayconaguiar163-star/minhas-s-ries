# 🎬 CineMaycon - Catálogo Personalizado de Séries

Um site moderno e responsivo desenvolvido para organizar, categorizar e gerenciar listas de séries favoritas, conteúdos em andamento e produções na fila para assistir.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização moderna, suporte a Grid Layout e design responsivo.
